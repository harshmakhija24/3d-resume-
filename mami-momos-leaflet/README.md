# Mami Momos — Two-Sided Leaflet

This is a standalone, static A5 leaflet for **Mami Momos**. It is intentionally isolated under `mami-momos-leaflet/` so the existing 3D-resume application at the repository root remains unchanged.

Open `index.html` in a modern browser to preview the design. The **Front** and **Back / Combos** controls swap the two sides. The **Print Both Sides** button prepares two A5 pages; use the printer setting **two-sided / flip on short edge**.

| Side | Purpose | Content to validate before print |
| --- | --- | --- |
| Front | Brand and visual identity | Logo/wordmark, headline, artwork, and final contact/social details if needed. |
| Back | Sales/menu side | Final combo prices, exact fillings, vegetarian/vegan call-outs, contact details, and allergen wording. |

The hero artwork is stored locally under `assets/jaipur-kyoto-hero.webp`, so the leaflet visual does not depend on the Manus preview URL.
